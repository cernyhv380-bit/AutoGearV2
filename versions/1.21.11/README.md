# AutoGearV2 — Minecraft 1.21.11

Исходники клиентского Fabric-мода AutoGearV2 для Minecraft **1.21.11**.

- Fabric Loader: **0.19.3**
- Fabric API: **0.141.6+1.21.11**
- Для сборки нужен JDK 21 или новее.

Чтобы собрать мод, выполните в этой папке:

```bat
gradlew.bat remapJar
```

Готовый JAR появится в `build/libs/`.
