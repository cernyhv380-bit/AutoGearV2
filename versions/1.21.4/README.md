# AutoGearV2 — Minecraft 1.21.4

Исходники клиентского Fabric-мода AutoGearV2 для Minecraft **1.21.4**.

- Fabric Loader: **0.16.14**
- Fabric API: **0.119.4+1.21.4**
- Для сборки нужен JDK 21 или новее.

Чтобы собрать мод, выполните в этой папке:

```bat
gradlew.bat remapJar
```

Готовый JAR появится в `build/libs/`.
