# AutoGearV2

Мод AutoGear для **Minecraft 26.3 (Fabric)** — сохранение и загрузка наборов инвентаря по бинду.

## Что умеет

- `F4` — надеть ранее сохранённый сет (броня, хотбар, левая рука, весь инвентарь — 41 слот).
- `F8` — сохранить текущий инвентарь как новый сет `set_N`.
- `Delete` — полностью очистить инвентарь (только в креативе).
- `G` — меню на ванильных виджетах: категории «Свои» / «По F8» / «Готовые»,
  поиск по сетам, добавление своего сета, список сетов, предпросмотр содержимого
  выбранного сета и кнопки действий.
- Команды: `/autogear save|load|select|list|delete|rename|reload`.
- Сеты хранятся в `AutoGear/sets/*.nbt` в папке игры, конфиг — `AutoGear/config.json`.

### Очистка инвентаря (`Delete`)

Очищает все 41 слот: инвентарь, хотбар, броню и вторую руку. В `Creative` работает сразу.
В `Survival` на разрешённых серверах — через тот же механизм временного креатива, что и
загрузка сета (переключение → очистка → возврат режима); на остальных серверах — сообщение
об ошибке. Кулдауна нет: повторное нажатие после завершения операции работает сразу.
Во время загрузки сета очистка не запускается.

### Перезапись через `/save`

`/autogear save <имя>` создаёт набор, если его нет, и **перезаписывает** существующий
(в том числе с отличающимся регистром — дубликатов не появляется):

```
/autogear save pvp     # создаёт pvp
/autogear save pvp     # перезаписывает pvp актуальным инвентарём
```

### Временный креатив на разрешённых серверах

На серверах **HypeMC / DexLand / MineBlaze** в режиме `Survival` нажатие `F4`
(загрузить сет) или `Delete` (очистить инвентарь):

1. сохраняет текущий режим;
2. отправляет `/gamemode creative`;
3. ждёт, пока клиент увидит `Creative` (таймаут 5 с);
4. выполняет задачу — загрузку сета либо очистку инвентаря;
5. ждёт завершения отправки пакетов **и ещё 10 игровых тиков**, чтобы сервер применил изменения;
6. только затем отправляет `/gamemode survival` и ждёт подтверждения (таймаут 5 с).

Если сервер не переключил режим — загрузка отменяется с сообщением. Если загрузка
завершилась ошибкой — режим всё равно восстанавливается. Если восстановить не удалось,
мод сообщает об этом и **не повторяет команды**. Повторные нажатия во время операции
игнорируются; при отключении/смене мира состояние сбрасывается.

На остальных серверах поведение прежнее: загрузка только в креативе.

Разрешённые домены по умолчанию: `hypemc.pro`, `dexland.org`, `mineblaze.net`, `mineblaze.ru`
(точное совпадение или поддомен). Переопределить можно в `AutoGear/config.json`:

```json
{ "allowedServers": ["example.com", "play.example.org"] }
```

> Мод работает **только в креативе** (временный креатив на разрешённых серверах — единственное
> исключение), потому что использует пакет `ServerboundSetCreativeModeSlotPacket`.

## Сборка

```bat
set JAVA_HOME=C:\dev\jdk25
cd C:\dev\projects\AutoGearV2
gradlew.bat build
```

Готовый jar: `build/libs/autogearv2-2.0.0.jar`.

> ВАЖНО для этой машины: JDK 25 должен лежать на обычном пути (`C:\dev\jdk25`).
> Если JDK лежит внутри OneDrive, JDK 25 не может писать файлы и Gradle падает на
> native-platform. JDK 21 для сборки не подходит — Loom 1.18 требует JVM 25.

## Хранение данных

- Наборы — `AutoGear/sets/<имя>.nbt` (41 `ItemStack`, кодируются `ItemStack.CODEC`).
- Конфиг — `AutoGear/config.json` (`activeSet`, `packetsPerTick`, `allowedServers`).
- Никакого шифрования, ключей, паролей и соли нет.

## GUI

Меню — обычный экран Minecraft на **ванильных виджетах**: стандартный фон, ванильный
список сетов (`ObjectSelectionList`) с тремя категориями:

| Категория | Что попадает |
|---|---|
| **«Свои»** | наборы с пользовательскими именами (всё, что не попало в две другие) |
| **«По F8»** | авто-сеты `set_N`, созданные клавишей `F8` |
| **«Готовые»** | всё, что лежит в папке `AutoGear/ready/` (включая подпапки-меты) |

Плюс поле **поиска** — оно **общее**: при вводе запроса список собирается из «Своих»,
«По F8» и «Готовых» одновременно, независимо от открытой вкладки. Ещё есть поле
**имени** с кнопкой создания своего сета из текущего инвентаря. Справа — предпросмотр
содержимого выбранного сета (броня, левая рука, инвентарь и хотбар с иконками предметов
и подсказками) и кнопки «Загрузить / Сохранить / Активный / Удалить / Закрыть».
Класс: `menu/AutoGearMenuScreen`.

Кнопка **«Загрузить»** работает так же, как `F4`: в креативе ставит сет сразу, а в
`Survival` на разрешённых серверах временно включает креатив, загружает сет и возвращает
прежний режим. Меню при этом закрывается, чтобы операция шла как обычное нажатие клавиши
(`GearActions.loadFromMenu` → `loadWithMode`).

## Готовые сеты: папка `ready/`

Готовые сеты больше не определяются по префиксу имени — их источник это папка
`AutoGear/ready/`. Всё, что там лежит, попадает во вкладку «Готовые». Файлы прямо в
`ready/` показываются своим именем, файлы из подпапок — как `мета/имя`:

```
AutoGear/ready/
  crystal.nbt
  web_crystal.nbt
  rocket_mace.nbt
  cpvp.nbt
  op.nbt
  beast.nbt
```

Как добавить сет из канала: сохранить `.nbt` из поста и положить в папку нужной меты.
Имя файла = имя сета в списке. Перезапуск не нужен — список читается при открытии меню.

Поиск пути: сначала `AutoGear/sets/<имя>.nbt`, потом `AutoGear/ready/**/<имя>.nbt`,
поэтому загрузка, удаление и переименование работают одинаково для всех категорий
(`SetStorage.resolveSetPath`).

### Что лежит в комплекте

| Сет | Что внутри |
|---|---|
| `crystal` | кристаллы, обсидиан, арбалет, элитра, жемчуг, тотемы, 7 стаков опыта, абсент |
| `rocket_mace` | булава + элитра + фейерверки, меч, топор, абсент и грог, 6 стаков опыта |
| `web_crystal` | кристаллы + паутина + обсидиан, арбалет, элитра, абсент |
| `cpvp` | кристалл-PvP: обсидиан, кристаллы, анкоры, светокамень, арбалет, топор, кирка, тотемы, опыт |
| `op` | pot-кит: сплэш-сила и сплэш-скорость пачками, жемчуг, меч, полный незерит |
| `beast` | минимальный дуэльный: алмазный меч, деревянный меч, алмазная броня |

Первые три — копии твоих `set_2`, `set_3`, `set_4`, последние три — копии `cpvp`, `op`, `beast`
после той же чистки. Сами исходные сеты в `AutoGear/sets/` не изменяются.

### Правила предметов в готовых сетах

- **узор брони** как в сете `pvp`: ботинки и штаны — `redstone` + `silence`,
  нагрудник и шлем — `netherite` + `silence`;
- **проклятие утраты, отдача и шипы вырезаны** — `vanishing_curse`, `knockback`, `thorns`
  удалены из всех предметов (в трёх сетах вырезано 51 зачарование);
- **у булавы ровно пять зачарований**: `density` V, `unbreaking` III, `mending`,
  `fire_aspect` II, `wind_burst` III (`breach` и остальные убраны);
- **обычных золотых яблок нет** — только яблоки с эффектом зелья (сила, невидимость,
  скорость, черепашка, регенерация, лечение, огнестойкость, слоу-фолл);
- **имена предметов ванильные** — `custom_name` сброшен; исключение — кастомные напитки
  сервера: у них имя приведено к типу напитка (`Грог`, `Медовуха`, `Абсент`) по полю
  `bukkit:drink`;
- **lore — только брендинг** AutoGear, три строки.

### Автоматическая нормализация

Правила применяются **автоматически**: при запуске игры (`SetStorage.init`) и при
каждом открытии меню (`AutoGearMenuScreen.init`) мод обходит сеты и приводит их
к правилам (`storage/ReadyNormalizer`):

- готовые сеты из `AutoGear/ready/**` — вырезаются отдача и шипы, **весь lore
  заменяется нашим брендингом**, на броню ставится узор из `pvp`;
- свои сеты и `set_N` из `AutoGear/sets` — затрагивает только тумблер проклятия
  утраты, остальное (зачарования, lore, узор) не меняется.

Файл перезаписывается только если что-то реально изменилось, поэтому повторный прогон
ничего не дублирует. Достаточно положить скачанный `.nbt` в нужную папку — при следующем
открытии меню он уже будет с вашим узором, без лишних зачарований и с нашим брендингом.

### Тумблер «проклятие утраты»

В правом верхнем углу меню есть кнопка `Проклятие утраты: ВКЛ/ВЫКЛ`:

- **ВЫКЛ** (по умолчанию) — `minecraft:vanishing_curse` вырезается у всех предметов;
- **ВКЛ** — наоборот, добавляется на каждый предмет.

Тумблер действует на **все** сеты: и готовые, и свои, и `set_N`. Состояние хранится
в `AutoGear/config.json` (`vanishingCurse: true/false`), переключение сразу
перезаписывает файлы.

### Подсказки и служебные кнопки

У всех кнопок, вкладок категорий, поля поиска и поля имени есть описание при наведении
мышкой. В нижнем ряду две дополнительные кнопки:

- **«Папка»** — открывает `AutoGear/ready` в проводнике (создаёт, если нет);
- **«TG»** — открывает канал `t.me/gigabyteqq` в браузере.

## Напитки сервера

| Напиток | Эффект | `bukkit:drink` |
|---|---|---|
| Медовуха | Скорость III | `medovyxa` |
| Абсент | Сила III | `absent` |
| Грог | Скорость II | `grog` |

Напиток — это `player_head` с текстурой профиля и `PublicBukkitValues.bukkit:drink`,
поэтому в сеты их нужно перетаскивать как есть (`set_1` — образец). Имя такого предмета
мод приводит к типу напитка: `Грог`, `Медовуха`, `Абсент`.

В готовых сетах сейчас есть только абсент и грог; медовуха осталась в `set_1`.

## Брендинг предметов

`storage/SetBranding` ставит три строки `minecraft:lore` с плавным красным градиентом:

```
ʙʏ:ɢɪɢᴀʙʏᴛᴇ11
ᴛ.ᴍᴇ/ɢɪɢᴀʙʏᴛᴇǫǫ
ᴀᴜᴛᴏɢᴇᴀʀᴠ2
```

Сеты игрока — «Свои» и созданные по `F8` (`set_N`) — **не брендируются**:
`SetBranding.isReadySet` реагирует только на имена с префиксом `pvp_`, `ready_`, `popular_`.
Исходные стеки игрока не меняются (работа идёт по копии), повторное сохранение
ничего не дублирует.

## Встроенные сеты

Мод приносит с собой шесть готовых сетов как образец структуры: они лежат в jar
(`src/main/resources/autogear/ready/<имя>.nbt`) и копируются в `AutoGear/ready/`
при первом запуске, если файла ещё нет. Папки мет создаются сразу. Удалённый вручную сет
сам не возвращается — факт установки запоминается ключом `bundledSets` в `config.json`
(текущая версия — 8).
