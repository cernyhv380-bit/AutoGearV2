# AutoGearV2

Клиентский мод для Minecraft на Fabric. Сохраняет и загружает наборы инвентаря, позволяет управлять ими через меню и команды.

## Возможности

- Сохранение и загрузка комплектов из 41 слота: инвентарь, хотбар, броня и вторая рука.
- Меню с поиском по наборам, категориями и предпросмотром предметов.
- Встроенные готовые наборы; дополнительные наборы можно поместить в папку `AutoGear/ready/`.
- Очистка инвентаря в творческом режиме.
- Клиентские команды для сохранения, загрузки, выбора, просмотра, переименования и удаления наборов.

## Клавиши

| Клавиша | Действие |
|---|---|
| `F4` | Загрузить активный набор |
| `F8` | Сохранить текущий инвентарь как новый набор |
| `G` | Открыть меню AutoGear |
| `Delete` | Очистить инвентарь |

Клавиши можно переназначить в настройках управления Minecraft.

## Команды

- `/autogear save <имя>` — сохранить или перезаписать набор.
- `/autogear load <имя>` — загрузить набор.
- `/autogear select <имя>` — выбрать активный набор для F4.
- `/autogear list` — показать сохранённые наборы.
- `/autogear rename <старое_имя> <новое_имя>` — переименовать набор.
- `/autogear delete <имя>` — удалить набор.
- `/autogear reload` — повторно загрузить активный набор.

## Ограничения

Загрузка и очистка используют creative-пакеты. Временное переключение режима в Survival предусмотрено для F4, Delete и загрузки из меню на серверах `hypemc.pro`, `dexland.org`, `mineblaze.net` и `mineblaze.ru`. Команда `/autogear load` доступна только в творческом режиме. Список разрешённых доменов можно изменить в `AutoGear/config.json`.

## Установка

1. Установите Fabric Loader и Fabric API для совместимой версии Minecraft.
2. Поместите скачанный JAR-файл в папку `mods` клиента.
3. Запустите игру с профилем Fabric.

Мод предназначен только для клиента.

## Сборка из исходников

Корневая папка содержит версию для Minecraft 26.3 и требует JDK 25. Выполните:

```bat
gradlew.bat build
```

Собранный мод появится в `build/libs/`. Исходники версий 1.21.11, 1.21.4 и 1.20.1 находятся в папке `versions/`; чтобы собрать JAR одной из них, перейдите в соответствующую папку и выполните `gradlew.bat remapJar`.

## Данные

Наборы и настройки сохраняются в папке игры:

- `AutoGear/sets/` — пользовательские наборы.
- `AutoGear/ready/` — готовые наборы.
- `AutoGear/config.json` — настройки мода.
